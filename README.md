# SubSmart 💳

A Subscription Management Dashboard built using React and Django.

## Features

- User Registration & Login
- JWT Authentication
- Add Subscription
- Edit Subscription
- Delete Subscription
- Dashboard Analytics
- Spending Overview
- AI Assistant
- Notifications
- Renewal Reminders
- Export PDF
- Export Excel
- Profile Management

## Tech Stack

### Frontend
- React
- Bootstrap
- Recharts

### Backend
- Django
- Django REST Framework
- JWT Authentication

### Database
- SQLite

## Installation

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
